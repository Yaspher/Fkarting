Nombre del proyecto: 
    FKarting

Tipo: 
    sitio web estático para un campeonato de karting con vista pública y panel administrativo.

Objetivo: 
    mostrar información del campeonato como ranking general, mejores tiempos, pilotos destacados y resultados de la última carrera.

Funcionalidad pública:
    Página principal con hero, ranking, tiempos, resultados y pilotos.
    Navegación responsive para móvil y desktop.
    Acceso a la administración desde el login.

Funcionalidad administrativa:
    Gestión de campeonatos.
    Registro y edición de pilotos.
    Creación y control de carreras.
    Carga de resultados.
    Configuración de puntos y ranking.
    ontrol de acceso por usuario y contraseña. 

Autenticación:
    El acceso al panel administrativo está protegido.

Credenciales indicadas en el README del proyecto:
    Usuario: admin
    Contraseña: fkarting2026

Tecnología:
    Frontend en HTML, CSS y JavaScript.
    Conexión con Supabase para consultar y actualizar datos.
    Sin backend propio; la lógica de datos se maneja a través de la API REST de Supabase.

Uso recomendado:
    Abrir la página principal para consultar información del campeonato.
    Usar la sección de administración para controlar datos del torneo.
